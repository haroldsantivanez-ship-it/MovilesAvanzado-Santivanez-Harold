# Requerimientos - Laboratorio 04 POO

## Requerimientos funcionales

| Código | Requerimiento | Descripción |
|---|---|---|
| RF01 | Crear clases | Implementar clases en Swift aplicando programación orientada a objetos. |
| RF02 | Definir propiedades | Utilizar propiedades para almacenar la información de los objetos. |
| RF03 | Implementar métodos | Crear métodos que permitan realizar las operaciones solicitadas. |
| RF04 | Crear objetos | Instanciar objetos a partir de las clases desarrolladas. |
| RF05 | Aplicar encapsulamiento | Organizar los atributos y métodos dentro de sus respectivas clases. |
| RF06 | Mostrar resultados | Presentar en consola los resultados obtenidos durante la ejecución. |
| RF07 | Resolver el ejercicio principal | Aplicar los conceptos de POO para desarrollar la solución solicitada en el laboratorio. |

## Requerimientos no funcionales

| Código | Requerimiento | Descripción |
|---|---|---|
| RNF01 | Lenguaje | El desarrollo debe realizarse utilizando Swift. |
| RNF02 | Entorno | El proyecto debe poder ejecutarse correctamente en Xcode. |
| RNF03 | Organización | El código debe mantenerse ordenado y entendible. |
| RNF04 | Control de versiones | Los avances del laboratorio deben registrarse mediante commits en Git. |
