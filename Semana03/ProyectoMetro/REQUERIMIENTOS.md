# Requerimientos Funcionales

## Sistema de Consulta del Metro de Lima y Callao

| Código | Función | Criterio verificable |
|---|---|---|
| RF-01 | Mostrar líneas | El sistema debe mostrar las líneas registradas del Metro de Lima y Callao. |
| RF-02 | Consultar estaciones | El sistema debe permitir seleccionar una línea y visualizar sus estaciones registradas. |
| RF-03 | Buscar línea | El sistema debe permitir buscar una línea mediante su código o nombre. |
| RF-04 | Buscar estación | El sistema debe permitir buscar una estación mediante su nombre. |
| RF-05 | Mostrar línea de una estación | Al buscar una estación, el sistema debe indicar a qué línea o líneas pertenece. |
| RF-06 | Mostrar lugares cercanos | El sistema debe mostrar lugares o puntos de referencia cercanos a una estación registrada. |
| RF-07 | Mostrar conexiones | El sistema debe listar las conexiones registradas entre líneas. |
| RF-08 | Identificar estación de intercambio | El sistema debe indicar cuándo una estación permite conexión entre dos líneas. |
| RF-09 | Ingresar origen | El sistema debe permitir ingresar una estación de origen para calcular una ruta. |
| RF-10 | Ingresar destino | El sistema debe permitir ingresar una estación de destino para calcular una ruta. |
| RF-11 | Calcular ruta directa | El sistema debe calcular un recorrido entre estaciones pertenecientes a una misma línea. |
| RF-12 | Calcular ruta entre líneas | El sistema debe encontrar una ruta entre estaciones de líneas diferentes cuando exista una conexión registrada. |
| RF-13 | Mostrar recorrido | El sistema debe mostrar en orden las estaciones que forman parte de la ruta calculada. |
| RF-14 | Mostrar total de estaciones | El sistema debe indicar la cantidad total de estaciones incluidas en la ruta. |
| RF-15 | Mostrar tramos recorridos | El sistema debe indicar la cantidad de tramos recorridos entre origen y destino. |
| RF-16 | Mostrar transbordos | El sistema debe indicar cuándo una ruta requiere cambiar de una línea a otra. |
| RF-17 | Contar transbordos | El sistema debe mostrar la cantidad total de transbordos realizados en la ruta. |
| RF-18 | Consultar estado de líneas | El sistema debe mostrar si una línea está operativa, en construcción o proyectada. |
| RF-19 | Validar línea | El sistema debe informar cuando el usuario ingrese una línea que no existe. |
| RF-20 | Validar estación | El sistema debe informar cuando una estación no se encuentre registrada. |
| RF-21 | Normalizar búsqueda | El sistema debe permitir búsquedas sin importar diferencias entre mayúsculas, minúsculas o tildes. |
| RF-22 | Validar opción del menú | El sistema debe informar cuando el usuario ingrese una opción que no pertenece al menú. |
| RF-23 | Nueva consulta | Después de realizar una operación, el sistema debe permitir regresar al menú principal. |
| RF-24 | Salir | El sistema debe finalizar únicamente cuando el usuario seleccione la opción de salida. |
